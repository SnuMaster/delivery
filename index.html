iPhone 단축어 직접 설정 방법 보기

단축어 앱에서 아래 순서대로 한 번만 만들면 됩니다.

  1. 단축어 앱 → 자동화 → ＋ → 메시지를 선택하고, 메시지 내용에 “운송장” 포함 또는 택배 발신자 조건을 고르세요.
  2. 실행 방식은 즉시 실행으로 바꾸세요. 처음 실행 때 iPhone이 네트워크 사용을 물으면 허용하면 됩니다.
  3. 텍스트 일치 동작을 추가하고 입력에 단축어 입력을 넣으세요. 정규식은 아래를 사용합니다.(?<!\d)\d{8,16}(?!\d)|\b[A-Za-z]{2}\d{9}[A-Za-z]{2}\b
  4. 일치 결과가 있을 때만 URL의 콘텐츠 가져오기를 추가합니다. 위 주소를 붙여넣고, 방법은 POST, 본문은 JSON으로 선택하세요.
  5. JSON 항목 key에는 위 연결 코드를, trackingNumbers에는 방금 만든 텍스트 일치 결과 변수를 넣으세요. 문자 원문·발신자·전화번호 항목은 넣지 마세요.

자동 등록된 번호도 택배사를 확정하지 않고 “공식 조회 필요”로 저장됩니다. 새 번호가 오면 택배허브에서 지금 동기화를 누르거나 페이지를 새로고침해 확인하세요.
