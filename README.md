# 택배허브

운송장번호를 한 화면에 모아 두고, 각 택배사의 **공식 배송조회**로 연결하는 개인용 웹앱입니다.

## 정확성 원칙

- 이 앱은 배송 상태·이력·도착 예정일을 자체적으로 수집하거나 만들어 내지 않습니다. 실제 정보는 `공식 조회`에서 확인합니다.
- 국내 숫자 운송장은 택배사별 길이와 앞자리가 겹칩니다. 숫자만 보고 CJ·한진·롯데 등을 자동 확정하지 않고, 사용자의 선택 또는 문자/메일에 함께 적힌 택배사 이름을 우선합니다.
- `AA123456789BB` 형태의 국제우편 S10 코드는 우체국 EMS·국제우편 **후보**로만 안내하며, 택배사 선택을 사용자에게 맡깁니다.
- 휴대폰 번호 하나만으로 모든 택배사를 통합 조회하는 공개 기능은 없습니다. 일부 개별 택배사의 본인확인 조회가 있더라도, 범용 자동 수집 기능으로 보이지 않게 설계했습니다.

## 할 수 있는 일

- 운송장·택배사·메모를 브라우저에 저장
- CJ대한통운, 한진택배, 롯데택배, 로젠택배, 우체국택배, 우체국 EMS·국제우편, 경동택배, 대신택배의 공식 조회로 이동
- 문자·메일에서 운송장 후보를 추출하고, 번호·택배사를 확인한 뒤 여러 개를 추가
- `공식 조회 필요` / `받음 (내 표시)`로 개인 관리 상태 표시
- JSON 백업 내보내기 및 안전한 병합 가져오기
- 모바일 대응 및 키보드/스크린리더 기본 접근성 지원

대신택배는 공식 조회 양식이 POST 방식이라, 앱이 사용자 클릭으로 공식 양식에 번호를 전달합니다. 다른 택배사는 확인된 공식 조회 링크를 사용합니다.

## 개인정보와 저장 위치

운송장번호와 메모는 로그인 없이 **현재 브라우저의 localStorage**에만 저장됩니다. 서버로 전송하거나 여러 기기와 동기화하지 않습니다. 공용 기기라면 사용 후 백업 파일과 브라우저 데이터를 관리해 주세요.

## 개발 및 검증

별도 패키지 설치 없이 정적 파일로 동작합니다. Node.js 22 이상에서 아래 검증을 실행할 수 있습니다.

```bash
npm test
```

테스트는 번호 정규화, 보수적 택배사 감지, 휴대폰 번호 제외, 일괄 추출, 공식 링크 생성, 백업 병합을 확인합니다.

## GitHub Pages 배포

`main`에 반영되면 GitHub Actions가 테스트를 통과한 정적 파일만 GitHub Pages에 배포합니다.

처음 한 번은 저장소에서 다음 설정을 켜야 합니다.

1. **Settings → Pages**로 이동
2. **Build and deployment → Source**를 **GitHub Actions**로 선택
3. **Actions → Validate and deploy GitHub Pages → Run workflow**를 실행하거나 `main`에 새 커밋을 푸시

배포 주소: `https://snumaster.github.io/delivery/`

GitHub Pages가 활성화되기 전에는 위 주소가 404를 반환하는 것이 정상입니다.
